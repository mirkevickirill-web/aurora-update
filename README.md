# Обновления «Авроры»

Публичная часть главного экрана «Аврора» для Android TV. Отсюда телевизор скачивает новые версии и свежие подборки фильмов.

- `version.json` — номер последней версии и что в ней нового.
- `apk/` — установочные файлы.
- `films.json` — новинки, популярное и лучшее. Собирается автоматически по понедельникам.

Источники для подборок: Wikidata, рейтинги Кинопоиска, Википедия (описания, CC BY-SA), YouTube (трейлеры).
